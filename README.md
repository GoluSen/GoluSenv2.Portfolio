# Golu Sen — Portfolio

Personal portfolio website. Built with plain HTML/CSS, dark terminal-inspired theme.

## Structure
```
.
├── index.html
├── assets/
│   └── style.css
└── README.md
```

## Run locally
Just open `index.html` in a browser — no build step needed.

## Deploy
Works as-is on GitHub Pages, Vercel, or Netlify (static site, no build command required).
