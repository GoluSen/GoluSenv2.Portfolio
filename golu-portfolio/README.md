# Golu Sen — Portfolio

Personal portfolio website of Golu Sen, React developer. Plain HTML, CSS and JavaScript with a dark, terminal-inspired theme. No framework and no build step.

**Live:** https://golusenportfolio.netlify.app

## Sections

- Hero with a short intro
- Experience (Linkific, React Developer Intern)
- Projects (Task Manager, Finance Tracker, QuizCrack)
- Skills
- Education and certifications
- Contact

## Features

- Responsive layout for desktop and mobile
- Scroll progress bar and a navbar that highlights the current section
- Hero fade-in and terminal-style typing for section prompts
- Scroll reveal for cards, lists and skills
- Hover lift and cursor-following highlight on project cards
- Respects `prefers-reduced-motion`, and the content stays visible if JavaScript is off

## Tech

HTML5, CSS3, JavaScript (vanilla), Google Fonts (JetBrains Mono, Inter)

## Run locally

Open `index.html` in a browser. No install or build step needed.

For a local server, use the VS Code Live Server extension, or run `npx serve .` in the folder that contains `index.html`.

## Deploy

Static site, no build command. Deployed on Netlify. It also works on GitHub Pages or Vercel.

If `index.html` is inside a subfolder of the repo, set that folder as the publish directory.
